1. Ecosistema Tecnológico Homologado

Estructura tecnológica y directrices de implementación unificadas para todos los grupos de trabajo:

🐘 Motor de Base de Datos: PostgreSQL

Administra integridad referencial estricta, restricciones CHECK, claves foráneas atómicas e identificadores autoincrementables enteros (bigserial / secuencias IDENTITY de 64 bits) optimizados para indexación B-Tree de alta concurrencia.

⚡ Backend & ORM: PHP 8.3 / Laravel 11

Modelado con Eloquent ORM nativo ($table->id()), tipado declarativo de atributos en el método casts() y encapsulamiento de lógica transaccional en clases de servicio bajo DB::transaction().

🛡️ Seguridad & Autenticación: Laravel Fortify

Autenticación headless robusta con soporte 2FA, reseteo de claves y enlace técnico directo inverso desde el padrón civil (persona) hacia la cuenta de acceso (users) mediante la clave foránea use_id.

🖥️ Capa Frontend SPA: Inertia.js + Vue 3

Patrón SPA monolítico moderno utilizando Vue 3 (Composition API con sintaxis <script setup>), contratos de tipado estricto en TypeScript e iconografía oficial de Lucide Icons.

📋 Validación Reactiva: Zod + vee-validate

Esquemas sincrónicos de validación en tiempo de ejecución en formularios cliente, coordinados con vee-validate para garantizar que los datos cumplan las limitaciones de PostgreSQL antes de ser enviados.

📐 Reglas de Modelado DB-SOGAC (.agents/AGENTS.md)

Nombres en singular snake_case, códigos mnemotécnicos de 3 letras por tabla y orden canónico obligatorio: 1. PK → 2. Negocio → 3. FKs → 4. Auditoría Estándar.

5. Directrices de Integración en el Stack Tecnológico

Pautas de desarrollo obligatorias para garantizar la interoperabilidad de los módulos construidos por los estudiantes:

1. Modelado Eloquent y Persistencia en Laravel 11

Todas las entidades deben extender de Illuminate\Database\Eloquent\Model utilizando la convención estándar de clave primaria autoincremental entera ($table->id()). Las claves foráneas se declaran con $table->foreignId('foo_id')->constrained(). La integridad y tipado de datos se declara en el método nativo casts() del modelo: 

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\SoftDeletes;

class InscripcionDetalle extends Model
{
    use SoftDeletes;

    protected function casts(): array
    {
        return [
            'fecha_inscripcion'        => 'datetime',
            'nota_final'               => 'decimal:2',
            'perdio_por_inasistencia'  => 'boolean',
            'status_id'                => 'integer',
        ];
    }
}

2. Vínculo Inverso Fortify y Modelo Unificado Persona

La tabla persona concentra la identidad civil completa del ciudadano (datos personales, atributos de estudiante y atributos de docente bajo el patrón Single Table Inheritance con campos opcionales/nulos). La entidad users se mantiene como una tabla técnica de credenciales pura (correo, contraseña, 2FA). La relación se modela de forma inversa 1:1: la tabla persona contiene la clave foránea use_id (foreignId('use_id')->nullable()->constrained('users')), permitiendo registrar personas sin cuenta de sistema y asociarles credenciales cuando se requiera.

3. Gestión de Permisos y Autorización (RBAC)

Las tablas de RBAC interactúan directamente con middleware en Laravel para proteger los endpoints de la API, delegando los permisos serializados a Vue 3 a través de Inertia ($page.props.auth.permissions) para ocultar o deshabilitar elementos de la interfaz dinámicamente según el rol contextual activo.

4. Gestión Transaccional en Clases de Acción (Services)

Operaciones complejas como la generación y cierre de actas (acta_calificacion), inscripciones masivas (inscripcion_detalle) y aprobación de admisiones deben encapsularse obligatoriamente dentro de transacciones de base de datos bajo el bloque: 

use Illuminate\Support\Facades\DB;

DB::transaction(function () use ($data) {
    // 1. Crear cabecera inmutable de acta
    $acta = ActaCalificacion::create([...]);

    // 2. Asentar calificaciones atómicas y congelar notas
    foreach ($data->estudiantes as $est) {
        $acta->detalles()->create([...]);
    }
});

5. Pipeline Inertia + Vue 3 + TypeScript + Zod

Los controladores despachan respuestas directas con Inertia::render(). Los contratos de datos en TypeScript reflejan identificadores numéricos estrictos. Los formularios en Vue 3 validan en tiempo real los valores de los cortes y notas mediante esquemas Zod conectados a useForm de vee-validate, garantizando que ninguna calificación enviada viole los límites porcentuales antes de alcanzar los endpoints de Laravel 11.
